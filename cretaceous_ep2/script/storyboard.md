# Раскадровка · Меловой период · Часть 2 «Не стреляй» (v2: камера и детали)
Стиль — как в Ч1 («бумажный театр»: плоские слои бумаги, белая кромка, тень на слой позади, бирка времени, субтитры-полоски). Время — оценка; финально подогнать по SRT из ElevenLabs.

## Словарь камеры (используй эти названия в задачах для Claude Code)
| Движение | Что делает | Длительность / сила |
|---|---|---|
| **НАЕЗД** | медленный zoom-in на объект | 3–6 % за шот, ease-in-out |
| **ТОЛЧОК** | резкий наезд на ударном слове | 8–12 % за 0,3 с, ease-out |
| **ОТЪЕЗД** | zoom-out, открывает масштаб | 10–25 % за 1,5–3 с |
| **ПРОЕЗД** | камера едет вбок вдоль сцены (pan), слои с параллаксом | дальний слой ×0,2, средний ×0,6, передний ×1,4 |
| **ПАНОРАМА ВВЕРХ/ВНИЗ** | вертикальный проезд (небо → земля и т. п.) | 1,5–3 с |
| **СКВОЗЬ СЛОЙ** | передний лист (папоротник, борт) уезжает за кадр, открывая сцену | 0,6–1 с |
| **РАЗРЕЗ** | вид «в разрезе» сбоку: стенка снята, видно всех внутри | статичная сцена + НАЕЗД |
| **СВЕРХУ** | вид сверху (top-down), схема/карта | + медленное вращение 1–2° |
| **POV** | вид глазами героя (смотровая щель, прицел) | рамка-маска + лёгкое дыхание камеры |

Всегда: «ручная» микротряска 2–4 px, параллакс 3 слоя, смена ракурса каждые 1,5–3 с, один и тот же переход два раза подряд — нельзя.

## Ночные детали (шоты 10–15)
- Небо: тёмно-синий картон `#121A2B` → у горизонта `#22304A`; **луна** — бумажный круг `#F3EDE0` с кальковым ореолом и 2–3 «кратерами» темнее; **звёзды** — 40–60 точек разного размера, 5–6 крупных четырёхлучевых на видимых нитках, мерцают (яркость ±20 %, 0,5–2 Гц).
- Силуэты деревьев и папоротников — чёрно-зелёный картон `#151A12`, по краю — холодный контровой от луны.
- **Светлячки**: 10–15 жёлтых точек с ореолом, медленно дрейфуют, гаснут и зажигаются.
- **Тёплые щели БТР**: из смотровых щелей и люка — полоски света `#FFB84D` (калька), ложатся на землю.
- Лёгкий туман-калька у земли, ползёт влево.
- Звук ночи: цикады + далёкий низкий рёв (1 раз).

## Новые ассеты для Ч2 (к тем, что уже есть из Ч1)
- Ночное небо: луна, звёзды на нитках, светлячки, туман у земли.
- БТР **в разрезе** (сбоку без стенки): лавки, лампа, четверо спящих, рация, решётка вентиляции.
- Смотровая щель — рамка-маска для POV.
- Бумажный череп рекса в разрезе (схема нюха).
- Дача: забор, мангал, собаки (3–4 силуэта, разные).
- Схема «палатка — 100 м — ящик», силуэт медведя.
- Банка тушёнки крупно + консервный ключ; полоски-запах (калька).
