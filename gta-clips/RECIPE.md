# Clipso — рецепт GTA 6 эдитов (разбор референсов)

Разобраны покадрово (6 к/с) + детект склеек и ударов в треке.
YouTube-референсы из сети среды не скачиваются — их нужно прислать файлами.

## Референс A — TikTok, «зашёл лучше всех» (13.5 с, 1080×1920, 60 fps, ~117 BPM)
Формат: **бит-эдит из официальных трейлеров**, без текста.
- **Склейка ровно на каждый удар**: шоты ~0.52 с (детект: 0.7, 1.47, 2.27, 2.8, 3.35, 3.85, 4.38, 4.9, 5.42 …).
  В кульминации — по полудоле (6.22 / 6.48, 10.43 / 10.7).
- **Цвет**: сильный грейд, насыщенные неоновые синие/пурпурные ночные кадры ↔ тёплые оранжевые закаты ↔
  бирюзовые пляжи. Контраст высокий, «сочно». Кадры подобраны по цвету блоками (ночь → день → закат).
- **Логотип игры** вспыхивает поверх кадров на ударах (2–3 раза) — главный «вау»-акцент.
- **Переходы**: белая вспышка на 1–2 кадра (frame white), резкие склейки; движение внутри шота
  (зум, проезд камеры трейлера) сохраняется — свои движения не перебивают.
- **Ритм**: 0–2 с зацепка (яркий кадр + логотип), середина — нарастание, финал на тёплом золотом кадре.
- Водяной знак автора внизу по центру, полупрозрачный.

## Референс B — ваш файл (17.4 с, 960×1280, 30 fps, ~81 BPM)
Формат: **мем-сравнение «как было / как стало»** с подписью.
- Текст по центру кадра, белый с выделением ключевого слова жёлтым:
  «what GTA 6 looked like in the **august** version:» → после перехода «in **november**:».
- Шоты длиннее: 0.8–1.5 с, склейки по ударам медленного трека.
- **Переход-«поворот»** в середине — вспышка/растворение в белое (~0.3 с), смена подписи.
- Финал: вспышка в белое → крупный план персонажа (панчлайн).
- Водяной знак автора внизу.

## Что из этого берём себе (свой стиль, не копия)
1. Склейки строго по ударам (детектор ударов → сетка), 1 удар = 1 шот, в кульминации полудоли.
2. Цвет-блоки + свой грейд (LUT/фильтр) единый для канала.
3. Свой акцент на ударах вместо чужого логотипа: вспышка, zoom punch, RGB split, shake, speed ramp.
4. Своя подпись-формат (например, мем-подписи «POV / when …») — крупный шрифт по центру, ключевое слово цветом.
5. Свой водяной знак «CLIPSO».

## Ограничения
- Фрагменты официальных трейлеров — коротко (≤1–2 с), трейлер целиком не перезаливать.
- Музыку в файл не вшивать без лицензии: экспорт без звука, трек — в приложении.
- Не использовать чужие эдиты как исходник — только официальные кадры Rockstar (трейлеры, показы, опубликованный геймплей) и свой геймплей.
