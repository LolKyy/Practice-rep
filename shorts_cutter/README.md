# shorts_cutter — нарезка длинных видео на Shorts / Reels / TikTok

Один скрипт превращает стрим, подкаст или интервью в готовые вертикальные ролики 1080×1920:

1. **Источник.** Локальный файл или ссылка (скачивает `yt-dlp`).
2. **Расшифровка.** `faster-whisper` с таймкодом каждого слова (результат кэшируется).
3. **Поиск моментов.** Каждый кусок из законченных фраз длиной от `--min` до `--max` секунд получает оценку:
   хук в первой фразе (вопрос, «!», цифры, слова вроде «секрет», «никогда», «ошибка»),
   громкость и пики (эмоции, смех), плотность речи, мало тишины, нет начала с «и/а/но/потому что».
   Берутся лучшие непересекающиеся куски.
   Можно задать свои таймкоды через `--clips`.
4. **Монтаж.** Вырезает паузы длиннее `--max-pause` и «эээ/мм», звук и картинка режутся по одной сетке кадров, поэтому рассинхрона нет.
5. **Кадр 9:16.** `crop` кадрирует по лицу (OpenCV), `blur` кладёт видео на размытый фон, `auto` выбирает сам.
6. **Субтитры.** Крупные, по 2–4 слова, ключевое слово выделено цветом, появляются с «поп»-анимацией. Плюс `.srt` для загрузки на YouTube.
7. **Динамика.** Панч-зум на смене фраз, нормализация громкости до -14 LUFS, фоновая музыка (`--music`).

## Установка

Нужны Python 3.9+ и [ffmpeg](https://ffmpeg.org/download.html) в PATH.

```bash
pip install -r requirements.txt
```

Модель Whisper скачается сама при первом запуске. Видеокарта NVIDIA используется автоматически.

## Примеры

Найти и нарезать 5 лучших моментов из ролика на YouTube:

```bash
python shorts_cutter.py "https://www.youtube.com/watch?v=XXXX" -n 5 --language ru
```

Сначала посмотреть, какие моменты найдёт скрипт, без рендера:

```bash
python shorts_cutter.py podcast.mp4 --language ru --dry-run
```

Нарезать по своим таймкодам, капсом, с музыкой:

```bash
python shorts_cutter.py stream.mp4 --clips "12:30-13:15, 1:02:10-1:02:50" --upper --music music.mp3
```

Видео на размытом фоне, субтитры по 2 слова, жёлтые ключевые слова заменить на зелёные:

```bash
python shorts_cutter.py interview.mp4 --layout blur --words 2 --highlight-color 39FF14
```

## Результат

В папке `shorts_out/`:

- `short_01.mp4`, `short_02.mp4`, … — готовые ролики;
- `short_XX.srt` — субтитры;
- `shorts.json` — таймкоды в исходнике, оценка, текст и идея названия для каждого ролика;
- `.work/` — кэш (скачанное видео, звук, расшифровка). При повторном запуске расшифровка не повторяется.

## Основные параметры

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `-n` | 5 | сколько шортсов сделать |
| `--min` / `--max` | 20 / 55 | длина момента в исходнике, с |
| `--clips` | — | свои таймкоды вместо автопоиска |
| `--model` | small | модель whisper: tiny, base, small, medium, large-v3 (точнее, но медленнее) |
| `--language` | авто | язык речи: ru, en, … |
| `--layout` | auto | crop (по лицу), blur (размытый фон), auto |
| `--max-pause` | 0.35 | паузы длиннее вырезаются; `--no-cut-pauses` отключает |
| `--zoom` | 0.08 | сила панч-зума, 0 отключает |
| `--music`, `--music-volume` | —, 0.12 | фоновая музыка и её громкость |
| `--words` | 3 | максимум слов на экране |
| `--font`, `--fonts-dir` | Arial | шрифт субтитров (нужна кириллица); папка со своими .ttf |
| `--font-size`, `--sub-y` | 92, 0.62 | размер и высота субтитров (0 — верх, 1 — низ) |
| `--upper` | выкл. | субтитры капсом |
| `--transcript` | — | готовая расшифровка JSON (`[{"start","end","text"}]`), whisper не запускается |
| `--crf`, `--preset` | 20, medium | качество и скорость кодирования |

Полный список: `python shorts_cutter.py -h`.

## Советы

- Используйте только своё видео или контент, на который есть разрешение автора.
- Для русского языка на CPU хорошее соотношение скорости и качества даёт `--model small`, для максимальной точности `--model large-v3` (лучше на GPU).
- Перед публикацией просмотрите ролики: автопоиск хорошо находит кандидатов, но последнее слово за вами. Если момент начинается не там, возьмите таймкоды из `shorts.json`, поправьте и перезапустите с `--clips`.
