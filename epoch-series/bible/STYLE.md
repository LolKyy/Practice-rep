# STYLE v2 — «Бумажный театр», светлее и живее
База — канон v1: `../cretaceous_ep1/script/style.md` (кромка, слои с тенью, латунные заклёпки, красная деталь, бирка, бумажные субтитры). Здесь — только то, что добавлено/изменено в v2.
Сравнение: `bible/style_guide_v1_vs_v2.png`.

## Неизменное (канон v1)
- Мир из цветной бумаги и картона слоями; у каждой формы белая кромка среза, мягкая тень между слоями.
- Герои — марионетки на латунных заклёпках, двигаются поворотом частей с «перелётом».
- Субтитры — бумажные полоски: белая полоска `#FBF7EC`, тушь Montserrat Black, ключевое слово на красной `#C8352B` (одно на фразу).
- Бирка на нитке (JetBrains Mono): время / день / «ГОД • МЕСТО».

## Что нового в v2 (как реализовано — `video/src/engine/`)
| Признак | Реализация |
|---|---|
| Настоящая бумага | `paper.ts`: 6 сортов (`card`, `kraft`, `water` — акварельная, `corr` — гофро, `trace` — калька, `felt` — ткань/фетр). Фактура 512² — многооктавный шум «облачности» массы + волокна + вкрапления |
| Неровность листа | рельеф каждого выреза: градиент свет/тень по направлению ключевого света + вогнутость по краю (аналог normal map) |
| Живые кромки | `tear()` с плавающим дрейфом и выщерблинами + торчащие белые волокна (`hairs`) |
| Глубина 5–7 планов | `stage.tsx` `<Plane z=…>`: z в метрах, параллакс и наезд ∝ фокус/z, ГРИП: размытие ∝ |1/z − 1/фокус| (макс. 9 px, фон должен читаться) |
| Свет | ключ сверху-слева (тёплое пятно), контровой ореол по краям (`rim`), лучи через кальку (`rays`), светлая виньетка. Дневной по умолчанию; `gold`, `dusk`, `night`, `indoor` |
| Поп-ап книга | `Stage pop=t`: каждый план встаёт из плоскости (rotateX 88°→0°) с перелётом, дальние раньше (`popOrder`) |
| Портал | `Portal`: вспышка → лист комнаты рвётся зигзагом с белой кромкой, половинки разлетаются → под ним поп-ап эпохи |
| Stop-motion | марионетки и бумага — «по двойкам» (15 к/с), камера — 30 к/с; «бум» ±0,8 px у каждого плана по двойкам |
| Тактильные мелочи (2–3 в кадре) | `tape`, `pencil` (разметка), `thread` (облака/солнце на нитках), `glue`, тень от толщины картона — встроены в декорации |

## Читаемость на телефоне
- Герой 45–60 % высоты кадра (масштаб марионетки `s≈5.4`), лицо в верхней трети (y < 640).
- Фон светлее v1, но чуть менее насыщен, чем герой; герой отделён контровым.
- **Зона субтитров 58–72 % (y 1114–1382)**, полоски стоят на y≈1240. Лица и важные детали туда не ставим.
- Безопасные поля: 90 px по бокам, 220 сверху, 300 снизу.
- Первые 3 с — всегда светло, сразу движение и голос (`check-frames` проверяет яркость кадра 0).

## Инфографика = бумажные предметы
`FactCallout` (жёлтый стикер + стрелка-полоска), `Ruler` (линейка роста), `PriceTag` (ценник на верёвочке), `CalendarCard` (отрывной), `MapCard` (крафт, пунктир, «ТЫ ЗДЕСЬ»), `SurvivalNotebook` (блокнот Сёмы), `ChoiceCard` («КУДА ДАЛЬШЕ?»).

## Технические правила
- Эмодзи в canvas не использовать (иконки — бумажные буквы/формы).
- Тень `paperShadow` + маленькие скруглённые плашки внутри повёрнутого/масштабированного контекста в swangle стирали холст → у плашек выбора тень рисуем подложкой `fillP`.
