# «ПОПАЛ В ЭПОХУ» — студия вертикальных роликов (TikTok / Shorts / VK Клипы)
Современный парень Сёма Котов (герой «Отряда БТР в меловом периоде») попадает в историческую эпоху и пытается выжить. Одна серия = одна эпоха, реальные факты, юмор, счётчик выживания. Сценарии и тексты озвучки приносит пользователь готовыми; моя задача — собирать серии по шаблону.

## Правила сессии (обязательно)
- В начале каждой сессии: `git pull`, молча прочитать `bible/STATE.md`, `bible/DECISIONS.md`, последние строки `bible/LOG.md` — и продолжать с места остановки, не переспрашивая.
- После каждого законченного шага: обновить `bible/STATE.md`, дописать строку в `bible/LOG.md`, коммит и push.
- Любое решение пользователя (цвет, форма героя, шрифт, формат) — сразу в `bible/DECISIONS.md`. Принятые решения не менять без согласия.
- Экономить лимиты: не переписывать работающие компоненты, правки точечно; черновики — 720×1280 (`<id>-draft`), финал 1080×1920 — один раз в конце; не пересобирать всё ради одной сцены (рендер `--frames=a-b`).
- Звать пользователя только: пароль/ключ ElevenLabs/доступ GitHub; что-то не скачивается (VPN); нужен перезапуск Claude Code для MCP (сначала обновить STATE.md, потом «перезапусти меня и напиши "продолжай"»); не найдены файлы стиля.

## Стиль (кратко; подробно — bible/STYLE.md)
«Бумажный театр» v2: цветная бумага слоями в 3D, белая кромка, тень между слоями, марионетки на латунных заклёпках, бумажные субтитры (Montserrat Black, ключевое слово на красной полоске), бирка на нитке. v2: процедурная фактура 6 сортов бумаги, рельеф, живые рваные кромки с волокнами; 5–7 планов на глубине с ГРИП и параллаксом; тёплый контровой, лучи через кальку; поп-ап раскрытие сцен; портал-разрыв листа; анимация «по двойкам» + «бум»; 2–3 тактильные мелочи в кадре. Первые 3 с светлые. Зона субтитров 58–72 % высоты — без лиц.

## Герой (кратко; подробно — bible/HERO.md)
Семён «Сёма» Котов, 23. Круглая голова, вихор из 3 зубцов вверх-вправо, круглые латунные очки, **красная деталь у горла `#C8352B` в любом костюме**, casual: горчичный анорак `#D9A23A`, синие штаны `#2E3A57`, коричневые ботинки `#5A3A24`, карандаш за ухом. Брови на шарнирах. HUD = блокнот Сёмы (ДЕНЬ / ЕДА / ШАНС ВЫЖИТЬ %, зачеркнул → написал) + бирка в углу. Для нового костюма — сначала лист «анфас + 3/4 + 4 эмоции» на утверждение.

## Шаблон серии (90–150 с)
1. 0–1 с КРУПНО Сёма пишет в блокноте (голос сразу) → вставка: страница, карандаш выводит эпоху/год, обводит «?!» → 2. ПОРТАЛ: ЭТОТ ЛИСТ рвётся, под ним поп-ап эпохи, Сёма падает в костюме («ХРУСТЬ!»), бирка «ГОД • МЕСТО». НЕ «диван + телефон» (это у референса) → 3. ЗАВЯЗКА (кем стал, 1–2 шота) → 4. БЫТ (4–6 шотов: FactCallout, PriceTag, Ruler, иерархия, распорядок; факт = картинка + шутка) → 5. СОБЫТИЯ (3–5 дат: CalendarCard + MapCard, блокнот переписывается) → 6. ИТОГ → 7. ФИНАЛ: QuestionPage — один вопрос «Куда отправить Сёму дальше?» на вырванном листе, БЕЗ вариантов.
Каждый факт = картинка + ГЭГ (Marks: sweat/bang/sparkle/crack, CoinGag и т. п.). Чередовать планы: крупный, вставка предмета, общий, наезд; не два одинаковых подряд. Кадры яркие.
Голос — рассказчик в 3-м лице, иногда прямые реплики Сёмы.

## Пайплайн
1. Озвучка: `python3 tools/tts-elevenlabs.py episodes/NN` (ElevenLabs, голос Dmitry, сразу voice.mp3 + timings.json — шаг 2 не нужен), либо ElevenLabs MCP (если подключён) или пользователь кладёт `voice.mp3`. Без ключа — черновик `node tools/tts-placeholder.mjs episodes/NN 1.3` (Piper).
2. `tools/timings episodes/NN` — faster-whisper small → timings.json (слова + шоты). Нужен доступ к huggingface.co (в облаке закрыт — запускать локально или черновые тайминги tts-placeholder).
3. Новая серия: `video/src/episodes/EpNN.tsx` по образцу `Showcase.tsx`, timings.json копируется в src, голос — в `video/public/<id>/`; добавить в `EPISODES` в Root.tsx.
4. `tools/render-draft <Id> episodes/NN` → показ → `tools/render-final <Id> episodes/NN` (H.264, loudnorm −14 LUFS, музыка −20 дБ).
5. `tools/check-frames episodes/NN/renders/final.mp4` — смотреть кадры 0/1/3 с/середина/конец: нет тёмного начала, текста за краем, субтитров на лице.
Партия сценариев — делать подряд, переиспользуя фоны (scenery.ts) и массовку (extra).

## Рендер (замер)
- Облако (без GPU, 4 ядра), замер на 10 кадрах: `angle` 1,3 с/кадр · `swiftshader` 1,5 · `swangle` 11 (!). Берём `--gl=angle`, `--concurrency=4`. Черновик Showcase (540 кадров 720p) — 3 мин. Браузер: `/opt/pw-browsers/.../chrome-headless-shell` (подставляется автоматически в tools/_env.sh).
- Локально Windows/Mac с GPU: тоже `angle`; `CONC=<ядра/2>` — при первом запуске сделать 5-секундный замер (`--frames=0-149`) и записать сюда.
- Не использовать эмодзи в canvas; `--scale` для черновика не работает (нечётные размеры) — есть композиции `-draft`.
