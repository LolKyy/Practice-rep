# UNSEEN REPS — заметки о формате (запомнить)

## Пожелания владельца канала
- Нравится: 3D-стиль (тёмный зал, глянцевый пол с отражениями, свет-лучи), живая камера.
- Ролики могут быть: (а) 3D-история + эдит в конце; (б) просто эдит.
- Музыка: в TikTok — трендовый звук добавляется в приложении; в файле — только лицензированная/своя.
- Видео делать ТОЛЬКО когда прямо попросят (не начинать рендер по своей инициативе).

## Разбор референса (lostthenfound5, 22 с, 576×576, ~99 BPM, шаблон одинаковый в обоих роликах)
1. **0–10 с — история-сравнение стикменов** (Perfectionist vs Action taker / 5 minutes vs No time),
   сплит-экран или два героя рядом, подписи моноширинным капсом.
2. **Вставки на битах внутри истории** (по 0.2–0.3 с, ровно на ударе):
   - светлая «матовая» плашка поверх кадра + нарисованный от руки круг «COMFORT ZONE» и пин «YOUR POTENTIAL»;
   - вспышка-карточка с фразой из будущего эдита («Comfort kills dreams.», выделение маркером) — анонс.
3. **Переход ~9.4–10.3 с:** бумажная карточка с фразой появляется маленькой и **рывками на каждом бите**
   растёт до полного экрана (с размытием движения) → начинается эдит.
4. **10–20 с — эдит из цитат**, смена на каждые 1–4 удара:
   «Comfort kills dreams.» (бумага, маркер) → «forget the old me.» (ч/б статуи, serif) →
   «Do it even if it hurts» (размытый эхо-текст) → «Always keep going.» (Сизиф) →
   «born to WIN» (фигура в луче света) → «ONE DAY / DAY ONE» (кинетический текст) → эндкарта.
5. Всё ч/б или почти ч/б, зерно, 1 акцент.

## Как это реализовано у нас
- `src/scenes/Pilot.tsx` — 3D-история «5:47 AM» + вставки на битах + рост карточки + эдит + концовка.
- Музыка-черновик с битом: `node tools/music.mjs <сек> <bpm> <дроп_сек>`; вставки ставить на кратные 60/bpm.
- `src/Edit.tsx` + `src/edit.json` — чистый эдит из картинок пользователя (`public/edit/`), нарезка по `tools/beats.mjs`.
