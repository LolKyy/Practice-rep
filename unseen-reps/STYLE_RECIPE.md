# Рецепт качества (разбор 19 топ-шортсов @drleonkessel)

Метод: замеры каждого кадра (яркость, контраст, насыщенность, движение), раскадровки 6 к/с,
покадровые полосы вокруг склеек; 5 агентов, по 3–4 ролика. Ролики: 15–41 с, 1080×1920, в основном 60 fps.

## Главное
- **Это 2D**, не 3D. Объём — от эффектов: свечение (bloom), конусы света в дымке, туман слоями,
  глянцевый пол с отражением, размытие фона (DOF), мягкие контактные тени, виньетка.
- **Тёмный мир + светящийся герой**: средняя яркость кадра 35–65/255, чёрный «приподнят» (18–40, не 0),
  фон < 80; герой — самое яркое в кадре (белый 230–255 + ореол). Статисты — серые 90–130, размытые.
- **Почти ч/б** (насыщенность 0–6) + **один цветовой акцент со смыслом** (красный галстук/неон/штамп,
  синий свет телефона, тёплая лампа, оранжевое пламя мотивации). Цвет/тепло растут только в финале.
- **Эмоция — позой и яркостью**, лиц нет: ссутулился, голова в руках, сел, кулак вверх; проигравший сереет.
- **Подписи-концепты**: крошечный моноширинный КАПС с широкой разрядкой (кегль ≈1.3–1.8 % высоты кадра,
  ~27 px), над головами, едут вместе с героем. Тема/название — по центру ~16 % сверху, весь ролик.
  Мораль — печатается (typewriter) в последних 25–30 %. Низ 20 % свободен под интерфейс TikTok.

## Камера и монтаж
- Кадр почти никогда не статичен: медленные наезды/отъезды/кран, всё с плавностью (ease-in-out).
- Размер героя: общий 12–25 % высоты кадра, крупный 35–50 %, финальный отъезд 2–5 % («крошечный герой — огромный мир»).
- Наезд: 0.7 с (резкий акцент) или 3–5 с (×1.3–2). Финальный отъезд 4–6 с (×5–10).
- Склейки: в спокойных роликах 2–7 шотов по 3–8 с; в динамичных — 1–2 с, в сетку бита (0.5 / ~1.05 с).
  Переходы: затемнение ~0.4 с, вспышка белым, «шторка» тёмным предметом, герой проходит перед камерой,
  монтаж по совпадению (герой в той же точке экрана при смене сцены).
- Зацепка ≤1.5 с: уже идёт действие / движение камеры / вспышка / сразу понятное сравнение A vs B.
- Начало: проявление из чёрного 0.15–0.3 с; конец: затемнение 0.6–1.2 с.

## Свет (на сцену — один «мотивированный» источник)
Конус сверху с пятном на полу, фонарь, настольная лампа, окно с лучами, свечение телефона, сияние горизонта.
Кульминация = световое событие (луч, рассвет, вспышка) на 45–75 % ролика, яркость +30–40.

| Параметр | Цель |

| Линия пола | 55–78 % высоты кадра |
