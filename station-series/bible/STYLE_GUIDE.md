## 1. Формат
- 1080×1920, 30 fps, H.264 CRF 18, AAC 320k, громкость −14 LUFS (`tools/render-final.mjs` делает сам).
- Серия 1 — до 2:00 (вышла 2:13), остальные — 80–90 с.
- Рендер — в облачной сессии Claude Code, mp4 отдаём пользователю файлом (в git видео не кладём).

## 2. Стиль рисовки — «кино-вектор + чёрная обводка»
- Плоский вектор, рисуется кодом (SVG в Remotion). Никаких картинок из интернета/нейросетей.
- **Мягкий свет:** градиенты, свечение (`feGaussianBlur`), отсветы источников на персонажах.
- **Персонажи — с толстой чёрной обводкой силуэта** (16 px), 2-тоновая светотень + полоса контрового света.
- **Режим «силуэт»** — для моментов страха: всё в черноту, видны только контровой свет по краю силуэта, бельма стылых, лёд, красная лампа. (`mode="sil"` у `Person`.)
- **Сплошной черноты нет:** всегда есть контровой свет — аварийный красный, голубое свечение льда, оранжевое тепло.
- Виньетка по краям кадра в каждой сцене (`<Vignette>`), лёгкая камера: медленный наезд 1.0→1.06–1.15 (`<Cam>`), тряска только на ударах.
- Иней ползёт по краям кадра, когда холодает (`HaronHUD frost` 0…1).

## 4. Шрифты (assets/fonts, кириллица проверена)
- **Montserrat Black** — караоке-субтитры.
- **JetBrains Mono Bold** — HUD, плашки, системные надписи, мониторы.
- **Oswald Bold** — заголовки, штампы («ЗАХВАЧЕНА»), «ЧАСТЬ N», трафареты («ПАЁК»).
- **Inter Black** — выноски (Callout), текст карточек.

## 5. Кадр и безопасные зоны (TikTok/Shorts)
- Верх 160 px и низ 420 px (ниже Y=1500) — под интерфейсом площадки, туда ничего важного.
- **Субтитры:** центр Y≈1290 (62–72% высоты), 84 px, 1 строка (макс. 2), ≤22 символа в группе, активное слово крупнее, одно ключевое слово красным. Обводка чёрная.
- **Глаза героя — в верхней трети** (Y < 640). Персонажи и важные объекты — выше субтитров.
- HUD занимает верх: таймер слева (60–620 × 160–290), кислород справа, под ними °C и схема слева, термосканер справа (720–1020 × 302–632). Центр (X 270–700) ниже Y≈300 — для лиц.
- **Окно связи Хорунжего** (`CommLink`) — слева над субтитрами (X 60–460, Y 1030–1150), горит оранжевым, когда он говорит.
- Выноски (`Callout`): «ИМЯ, ВОЗРАСТ / РОЛЬ», не перекрывать лица и HUD.

## 6. HUD «Харона» (`video/src/components/HaronHUD.tsx`)
- **ДО ПАДЕНИЯ** — красный таймер ЧЧ:ММ:СС, тикает. Серия съедает ~50–55 мин таймера (`timeScale` для монтажного сжатия).
- **КИСЛОРОД %**, **ОТСЕК: −N°C** (или «ТЕМП. ТЕЛА: 35,1°» через `tempLabel/tempText`), **мини-схема 5 палуб** с мигающей точкой.
- **Термосканер** — круглый радар: оранжевые точки — живые, голубые — холодные/стылые. Подписи: «ХОЛОДНАЯ ЦЕЛЬ — 6 м» (до серии 2) → «СТЫЛЫЙ — 6 м» → «СТЫЛЫХ: 3 • БЛИЖАЙШИЙ 6 м». В серии 1 появляется только после находки (`scannerFrom`).
- **«ОБНАРУЖЕН»** (`detectAt`) — фирменная подпись сериала: красная вспышка по краям + помеха по HUD + двойной писк (`scanner_detect`). Одинаково в каждой серии.
- Вне станции (флешбэки, Земля) HUD скрываем или оставляем только таймер (`parts`). В спокойные моменты — `dim` (−30%).

## 7. Персонажи (`video/src/rig/Person.tsx`)
- Риг: суставы с углами (0° — вниз, 90° — вправо, 180° — вверх), конечности — сужающиеся капсулы, голова ×1.32 (крупно, читаемо с телефона).
- Готовые облики `LOOKS`: `glebNoScan` (до находки сканера) / `gleb` (со сканером), `eva`, `guardFrozen` (ледяная статуя), `stylyy`.
- Пропсы: `pose`, `emotion` (neutral / tense / fear / determined / closed), `facing`, `light` (направление НА источник света), `rim` (цвет контрового: лёд `#9FE3FF`, красный, тёплый `#FFE3C8`), `item="crowbar"`, `mode="sil"`.
- Узнаваемость: Глеб — шрам через бровь, щетина, наушник за ухом, роба 0731; Ева — каре, белая форма комиссии, планшет на запястье; стылый — оранжевая роба, кристаллы из плеч, бельма, светящиеся прожилки, пар изо рта. **Стылых показываем частями и в полутьме**, чаще силуэтом.
- Хорунжий до серии 12 — только голос и аватар в `CommLink` (силуэт с погонами).
- Новых героев (Вадим, Гоша, Мельник, Шрам, Хорунжий, председатель) добавлять как новые `LOOKS` по `CHARACTERS.md`.

## 10. Звук и музыка
- Звуки синтезирует `tools/make_sfx.py` (у ключа нет права Sound Effects): `ice_crunch(_long)` — **фирменный хруст**, `ice_crack`, `crowbar_clang`, `scanner_detect` (двойной писк), `scanner_ping`, `turret_scan` (тихо, ≈0.15–0.2), `cryo_hiss`, `whoosh`, `boom`, `glitch`, `dock_clamp`, `lid_open`, `drone_station` (гул станции, 0.35, на палубах станции).
- Музыка — `assets/music/haron_bed.mp3` (тёмный эмбиент), громкость ≈0.16 под голосом. **На клиффхэнгере музыка исчезает** — остаются хруст и тишина.
- Если включат Sound Effects у ключа — заменить синтез хруста/скрипа на сгенерированные (тот же файл, то же имя).

## 11. Структура серии (по формуле + решения пользователя)
1. **0–2 с — хук:** самый сильный кадр + одна фраза, HUD виден с первого кадра, первый кадр не чёрный.
2. **2–8 с — кто ты и где ты** (выноска «ИМЯ, ВОЗРАСТ / …»).
3. Одна угроза, одно правило, 1–2 улики (плашки, мониторы, схема).
4. Клиффхэнгер → 1,5 с тишины → **плашка «ПОДПИШИСЬ, ЧТОБЫ НЕ ПРОПУСТИТЬ — ЧАСТЬ N+1»** (без голоса, 2,8 с).
5. **Вопроса в комменты в конце нет** (решение пользователя). Вопрос можно дать текстом в закреплённом комментарии.

## 11а. Начало серии 2+ (для новых зрителей)
Хук 0–3 с (самый сильный кадр + фраза-правило/ставка) → «◀◀ РАНЕЕ» 12–16 с: нарезка сцен прошлых серий (обесцвечено, плёночные полосы, белые вспышки на склейках) под рассказчика: кто ты, где, зачем, что случилось в прошлой серии → действие. Образец — `video/src/episodes/ep02/scenes.tsx` (`SRecap`).

## 11б. Зоны текста (чтобы ничего не наезжало)
`video/src/haron/layout.ts`: HUD (Y 160–640 по бокам) · CONTENT (Y 660–1010) — все плашки, правила, штампы, выноски · COMM (Y 1030–1150, слева) — окно связи · SUBS (Y 1190–1390) — субтитры · ниже 1500 — ничего важного. `Plate` сама поднимается, если её поставили на окно связи/субтитры. Важный объект (колония, дверь, кнопка) — тоже не ниже Y≈1010.

## 12. Как сделать новую серию (рецепт)
```bash
# 0. память: git pull; прочитать bible/STATE.md, DECISIONS.md, HARON_bible_v3.md (серия N), этот файл
# 1. сценарий → episodes/epNN/script.txt (согласовать с пользователем!)
# 2. реплики → episodes/epNN/lines.json (как в ep01: id, scene, role, pre, text; voices; tempo; preScale; tail)
.venv/bin/python tools/make_voice.py epNN --dry      # сколько символов уйдёт
.venv/bin/python tools/make_voice.py epNN            # озвучка + Whisper-сверка + voice.mp3/timings.json/timeline.json
# 3. монтаж: скопировать video/src/episodes/ep01 → epNN, переписать scenes.tsx (сцены по id из lines.json),
#    в EpNN.tsx — звуки (add(...)), ключевые слова субтитров; зарегистрировать композицию в Root.tsx
# 4. кадры для проверки (быстро, по кадру на сцену)
cd video && npx remotion still src/index.ts EpNN out/epNN/<сцена>.png --frame=<N> --scale=0.5
# 5. финал + проверка
node tools/render-final.mjs EpNN --ep epNN
node tools/check-frames.mjs episodes/epNN/renders/EpNN_final.mp4
```
Проверять глазами: кириллица, ничего под HUD/субтитрами, глаза героя в верхней трети, первый кадр не пустой, у героев нет предметов «из будущего» (сканер до находки и т.п.), громкость звуков (скан тише голоса).

## 13. Известные ограничения / что улучшать
- Анимация персонажей простая (позы, руки, голова, камера) — нет ходьбы с шагами, мимики губ под речь.
- Звуки синтетические.
- Иногда в субтитрах висит короткий предлог в конце группы («…КОНТЕЙНЕР С») — при желании доработать `groupWords` (не оставлять предлог в конце).
