# Раскадровка · Меловой период · Часть 3 «Ворон»
Стиль — как в Ч1–Ч2 («бумажный театр»: слои бумаги, белая кромка, тень на слой позади, бирка времени, субтитры-полоски). Рекс — без изменений (в этой серии не появляется). Время — оценка; финально подогнать по SRT из ElevenLabs.

## Словарь камеры
| Движение | Что делает | Длительность / сила |
|---|---|---|
| **НАЕЗД** | медленный zoom-in | 3–6 % за шот |
| **ТОЛЧОК** | резкий наезд на ударном слове | 8–12 % за 0,3 с |
| **ОТЪЕЗД** | zoom-out, открывает масштаб | 10–25 % за 1,5–3 с |
| **ПРОЕЗД** | камера едет вбок, слои с параллаксом | дальний ×0,2, средний ×0,6, передний ×1,4 |
| **ПАНОРАМА ВВЕРХ/ВНИЗ** | вертикальный проезд | 1,5–3 с |
| **СКВОЗЬ СЛОЙ** | передний лист уезжает за кадр | 0,6–1 с |
| **РАЗРЕЗ** | БТР сбоку без стенки, видно всех внутри | + НАЕЗД |
| **СВЕРХУ** | вид сверху | + вращение 1–2° |
| **POV** | глазами героя (щель, люк) | рамка-маска + дыхание камеры |
| **ТРЯСКА** | удар по броне: все слои дрожат, дальние слабее | 0,3–0,5 с |

Всегда: микротряска 2–4 px, параллакс 3 слоя, смена ракурса каждые 1,5–3 с, один переход два раза подряд — нельзя.

## Атмосфера
- **Ночь (шоты 1–10):** как в Ч2 — луна с ореолом, звёзды на нитках, туман-калька у земли, тёплые полоски света из щелей БТР. Светлячков нет (стая рядом — всё затихло).
- **Рассвет (11–16):** небо от тёмно-синего к персиковому `#F2B48A`, солнце — бумажный круг из-за деревьев, длинные тени, роса-калька на папоротниках.
- **Рапторы:** см. `characters.md` → РАПТОР. Пять особей, вожак с рваным пером. Глаза ночью — жёлтая калька, светятся.
