# Задание: «Меловой период» · Часть 3 — «Ворон»

Сделай третью часть так же, как `cretaceous_ep2` (тот же движок, стиль, персонажи, субтитры). Код можно взять из `cretaceous_ep2` как основу — заново его не изучай, сюжетные файлы прошлых частей не нужны.

Читать только папку `cretaceous_ep3/script/`:
- `script.md` — сценарий (16 абзацев = 16 шотов) + заметки по фактам
- `storyboard.md` — раскадровка: камера (словарь в начале), ракурсы, свет, звук, красное слово субтитра, список новых ассетов
- `characters.md` — персонажи; **новое: РАПТОР** (5 особей, перья слоями бумаги, коготь-серп, вожак с рваным пером) и ВОРОН (только голос). Рекса не менять — в Ч3 он не появляется.
- `style.md` — стиль канала
- `voice_elevenlabs.txt` — текст озвучки (для справки; куда вставлять реплики Ворона — в конце файла)

Аудио (положит автор):
- `script/voice_main.mp3` + `script/voice.srt` — рассказчик; тайминги шотов и субтитров — из SRT
- `script/voron_01.mp3` … `voron_05.mp3` — реплики Ворона; вставить в паузы по списку из `voice_elevenlabs.txt`, эффект рации: полоса 300–3000 Гц, шум, треск в начале и конце

Важно:
- камера всегда живая, ракурс меняется каждые 1,5–3 с, один переход два раза подряд нельзя;
- ночь (шоты 1–10) — как в Ч2, но без светлячков; рассвет (11–16) — персиковое небо, длинные тени;
- в начале — шот 0 «Ранее» (2–3 с): быстрая нарезка кадров из готовых роликов Ч1–Ч2, бирка «РАНЕЕ»; затем хук;
- в конце бирка «ЧАСТЬ 4 →».

Сначала покажи 3–4 ключевых кадра в `keyframes/`, потом рендери весь ролик 1080×1920 → `melovoy_ep3_voron.mp4`.
