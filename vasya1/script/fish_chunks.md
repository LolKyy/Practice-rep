**1**
```
[excited] Твой друг Жека, сука, проснулся пришельцем. Ровно на сутки. И, кроме тебя, всем похуй.
Семь ноль-ноль. Жека шлёт голосовое. Там только: «А Вась?» Открываешь дверь — на пороге зелёный пришелец в его тельняшке.
```

**2**
```
[excited] Восемь ноль-ноль. Мама Жеки ставит ему кашу: «Вась, ешь, остынет». Ей вообще всё равно.
Девять ноль-ноль. Пара. Препод отмечает: «Жеков?» — «Вась». — «Присутствует».
```

**3**
```
[excited] Одиннадцать ноль-ноль. Жека ловит вай-фай антенной. Вся группа садится вокруг него. Пять палок даже в подвале.
Тринадцать ноль-ноль. Шаурмичная, без очереди. Продавец: «Тебе как обычно, Вась?» Жека тут впервые.
```

**4**
```
[excited] Восемнадцать ноль-ноль. Жека идёт на свидание вместо тебя. Девушка смеётся: «Реально, Вась». Теперь она пишет ему, а не тебе.
```

**5**
```
[excited] Двадцать ноль-ноль. У подъезда гопники. [tense] «Слышь, ты кто такой?» — «Вась». — «Семки будут?» — [whispers] «…А Вась?» Пауза. Главный молча отсыпает ему семок: «Садись, Вась».
Полночь. Жека снова человек. Потягивается: «Ну всё. Свась».
```

**6**
```
[excited] Ты идёшь чистить зубы. Смотришь в зеркало, [tense] а у тебя антенна. Из-за двери мама: [whispers] «А Вась?»
Кто из твоих друзей стал бы Васей первым? Отметь его в комментах.
Подпишись, чтобы не пропустить.
```
