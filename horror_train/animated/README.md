# «Не открывай дверь» — анимированная версия (часть 1)

Готовый ролик в формате survival-историй: плоская иллюстрация, караоке-субтитры (сказанные слова белые, ключевое — красное), HUD с местом, временем и счётчиком стуков, финальный выбор «А или Б».

**Готовое видео:** `out/train317_part1.mp4` — 1080 × 1920, 30 fps, 1:40, озвучка ElevenLabs.

**Голос:** ElevenLabs, весь текст одним куском. Запись разрезана на 15 фраз по SRT из ElevenLabs и выровнена на −15 LUFS. Тайминг фраз лежит в `voice/<id>.cues.json`: по нему слова в субтитрах загораются вместе с речью. Если файла `.cues.json` нет, тайминг берётся из пауз в записи.

Всё нарисовано и анимировано кодом (`render.py`), без генераторов картинок. Звук: ветер, стук колёс, тормоза, щелчки реле, помехи динамика, удары по стеклу и двери, треск дуги, бас — синтезированы.

**Голос:** синтезатор RHVoice, голос «Александр» (aleksandr-hq), темп 88 %, высота 92 %, обработка — тёплый эквалайзер, компрессор, лёгкая комната, −16 LUFS. Записи — `voice/01.wav` … `15.wav`. Субтитры привязаны к паузам в записи, поэтому слова загораются вместе с речью.

## Сюжет (story.json)

15 сегментов: текст диктора, сцена, слова, выделенные красным, HUD, события (стук, вспышка, звук) и подписи. События привязаны к словам: `{"type": "knock", "word": "постучали", "offset": 0.9}` — удар через 0.9 сек после слова «постучали». Поменял текст — события сами сдвинулись.

Сцены: `train`, `conductor`, `window`, `tambour`, `corridor`, `journal`, `footprints`, `circle`, `speaker`, `choice`.

**Деталь для пересмотра:** в сцене с кругом Дима насчитал семь. Восьмой стоит в тени у двери вагона, без номера. В первых двух сценах на горизонте справа виден высокий силуэт — ещё до остановки поезда.

## Как заменить голос

- **Синтезатор заново** (после правки текста): `python3 animated/make_voice.py`, или `--only 05 06` для отдельных фраз. Нужен собранный RHVoice (github.com/RHVoice/RHVoice).
- **Свой голос / CapCut / ElevenLabs:** положи WAV с тем же именем (`voice/05.wav`), текст — поле `text` в story.json.

Потом `python3 animated/render.py`: сегменты подстроятся под длину записей, слова в субтитрах — под паузы в речи.

**Ударения.** Синтезатор иногда ставит ударение не туда. Проверь на слух, особенно «замёрз», «сцепку», «Петровича». Если ошибся, можно перезаписать эту фразу своим голосом.

## Команды

```bash
python3 animated/render.py                # весь ролик (~6 мин рендера)
python3 animated/render.py --stills       # по кадру из каждого сегмента → out/stills/
python3 animated/render.py --preview 5 8  # только сегменты 05–08
```

Нужно: Python 3.10+, numpy, Pillow, ffmpeg.
