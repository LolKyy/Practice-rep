# Часть 3 — «Восьмой»

Хронометраж ~2:20–2:35, 32 сегмента. Зрители выбрали **Б — пройти мимо**.

- `voice_text_elevenlabs.txt` — текст для озвучки, одним куском (абзац = сегмент).
- `story_part3.json` — сценарий для рендера: текст, сцены, HUD, красные слова, звуки, подписи.

## Сюжет коротко

Дима проходит мимо «Петровича». Чёрная лужа тянется за ним, Дима отпугивает её зажигалкой: вода шипит и отползает. Из лужи поднимается рука с длинными пальцами; огонь загоняет её обратно. «Петрович» сползает со скамьи пустой, как пальто: *оно из него вытекало*. Второй вагон, штабной: 8 горячих стаканов чая, людей нет, под стаканом памятка 1954 года — правила 1–3, дальше оборвано. Сзади голосом Петровича: «Дима, ты дверь закрыл?» — но Петрович не знал его имени. Мокрые босые шаги. Газ кончается, огонь синий. Дверь кабины, Дима стучит три раза — как они. Двустволка в окошке: «Сколько их?» — «Семь». — «Восемь». Откуда машинист знал? Зажигалка гаснет, у самого уха голосом Димы: «Семь». «Парень… вас там двое?» Выбор.

## Озвучка ElevenLabs

- Тот же голос, что в частях 1–2. Весь текст одним генерированием, чтобы тембр не плавал.
- Проверить ударения: «щёлкнул», «взвёл», «пятьдесят четвёртый», «подстаканниках», «сполз».
- Реплики в «» — тише и ровнее, без актёрства: это копия чужого голоса. «Семь» в сегменте 29 — почти шёпотом.
- Экспортировать MP3/WAV + SRT, положить в `animated/part3/voice/full.mp3` и `full.srt`.

## Новые сцены (нарисовать в стиле render.py)

| Сцена | Что на экране |
|---|---|
| `petrovich` | Вагон 3 из части 2: выбитое окно, буран в купе, «Петрович» спиной в кителе и фуражке, капает чёрное, лужа. `slumped` — китель осел на пол пустым, фуражка откатилась |
| `puddle` | Крупно пол: чёрная лужа, сапог Димы, рука с зажигалкой сверху. `crawl` — край лужи ползёт к сапогу. `recoil` — от огня лужа отдёргивается с паром. `fingers` / `hand_rise` — из лужи поднимаются длинные тонкие пальцы (силуэт, без деталей). `burn` — вспышка, пальцы уходят вниз |
| `staffcar` | Штабной вагон, тёплый полумрак от зажигалки, иней ползёт по стёклам. Стол, 8 стаканов в подстаканниках, пар поднимается |
| `memo` | Как `journal` из части 1: пожелтевший листок, машинописный шрифт. Заголовок «ПАМЯТКА МАШИНИСТУ. ПЕРЕГОН 140–150 КМ. 1954». Строки 1–3 проявляются по словам, ниже рваный край |
| `corridor_lighter` | Тёмный коридор с огоньком зажигалки из части 2, вид вперёд. `wet_steps` — сзади на полу мокрые следы босых ног. `flame: blue` — огонь синий и маленький |
| `cabdoor` | Торец вагона, дверь кабины с маленьким окошком. `barrels` — в окошке два ствола двустволки |
| `dark` | Почти полная темнота, только субтитры. `barrels_glint` — блик на стволах |
| `choice` | Как в части 2, с миниатюрами; подписи панелей берутся из `params.a` / `params.b`, низ — `params.footer` |

Правила стиля: огонь — единственное тёплое пятно, всё остальное сине-серое. Существо никогда целиком и без лица.
