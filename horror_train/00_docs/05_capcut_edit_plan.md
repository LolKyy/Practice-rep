# Монтаж в CapCut — пошаговый план

CapCut Desktop (Windows/macOS). Мобильная версия умеет то же самое, только пункты меню называются иначе. Названия ниже даны по русской локализации, в скобках — английские. В разных версиях CapCut пункты немного различаются.

> Claude Code не управляет CapCut напрямую. Всё ниже делается руками. Таймкоды, файлы, оверлеи и черновой звук уже подготовлены.

---

## 0. Подготовка (5 минут)

1. Собери все материалы по папкам (см. README). Проверь, что для каждого кадра из `shotlist.csv` есть файл в `02_images/` или `03_video_clips/`.
2. Сгенерируй служебные файлы: `python3 tools/build_assets.py` (оверлеи, черновой звук, аниматик).
3. **Новый проект** → *Соотношение сторон (Ratio)* **9:16** → *Разрешение* **1080p**, *Частота кадров* **30**. Сохрани проект в `08_capcut_project/`.

## 3. Переходы

Почти везде **жёсткая склейка**. Плавные переходы ломают ощущение записи. Исключения:
- S01B → S02A: *Растворение (Dissolve)* 0.2 сек.
- S05A → S05B: *Whip pan / Размытие в движении* 0.3 сек.
- S06C → S07A: *Глитч (Glitch)* 0.2 сек.

## 4. Цветокоррекция

Создай **корректирующий слой** (*Коррекция (Adjust) → Добавить корректирующий слой*) на всю длину над V1:

| Параметр | Значение |
|---|---|
| Температура | −25 |
| Оттенок | −5 (к зелёному) |
| Насыщенность | −35 |
| Экспозиция | −10 |
| Контраст | +12 |
| Светлые участки | −20 |
| Тени | −15 |
| Виньетка | +30 |
| Резкость | −10 |
| Зернистость (если есть в версии) | +20 |

Для CCTV-кадров (S03B, S07A, S07B) отдельно: насыщенность **−100** и оттенок **−15**: серо-зелёный монохром камеры наблюдения.

Аварийная лампа должна остаться **единственным тёплым пятном**. Если после коррекции она стала серой, на кадрах S02B, S05A, S05C подними насыщенность клипа до −15.

## 5. Шум и артефакты

1. V3: `06_overlays/vhs_noise.mp4` (6 сек, бесшовная петля) — повтори на всю длину. *Режим наложения* **Экран (Screen)**, *Непрозрачность* 25 % (на CCTV-кадрах 35 %).
2. Эффект *VHS / Ретро* на корректирующий слой, если есть в библиотеке: интенсивность 20–30.
3. Глитч-всплески (эффект *Glitch*, 3–5 кадров): **0:10.8** (обрыв питания), **0:21.6** (помехи обрываются), **0:48.2** (дверь), **1:12.8** (голос снаружи), **1:16.0** (обрыв записи).
4. Никаких глитчей между ними: артефакт должен значить событие.

## 6. Титры

PNG из `06_overlays/` на V5 (они уже 1080 × 1920 и расставлены по кадру). Если хочешь набирать текст в CapCut:
- шрифт: моноширинный (например, *Courier Prime* / *IBM Plex Mono*), белый, 52–60 px;
- позиция: нижняя треть, но выше интерфейса TikTok (не ниже 75 % высоты кадра);
- анимация появления: *Печатная машинка (Typewriter)* для `03:17…` и `ЗАПИСЬ ПРЕРВАНА…`, без анимации для хука.

## 7. Субтитры

*Текст → Субтитры → Импорт (Import captions / Local captions)* → `05_subtitles/subtitles_ru.srt`.
Стиль: белый, без плашки, тень 40 %, шрифт без засечек 46 px, по центру на высоте ~62 %, **не пересекать** титры V5.
Проверь, что строки не вылезают за безопасную зону (поля 90 px по бокам).

## 8. Звук

1. A1: `04_audio/temp/temp_mix.wav` от 0:00. Это **разметка**: по её щелчкам и ударам ставь настоящие SFX. Перед экспортом — выключи (иконка динамика на дорожке).
2. A2 ветер: `amb_wind_blizzard.wav` петлёй до 1:16.0. Ключевые кадры громкости по строкам `wind_level` из `audio_cues.csv` (−16 → −34 на 0:12.6 и т. д.). На 0:59.2 — резкий провал до −60 дБ, на 1:16.05 — вырезать.
3. A3: `amb_train_running.wav` 0:00–0:10.8, затухание 0:07→0:10.8 (замедление: *Скорость* 1.0× → 0.8× с 0:07, *Сохранять тон* выкл.). `mus_drone_low.wav` 0:25–0:59, −30 дБ, плавный вход 2 сек.
4. A4 SFX: по таймкодам из `audio_cues.csv` / `04_sfx_prompts.md`.
5. A5 голоса: таймкоды и обработка — `03_voiceover.md`.
   - Объявления 0:15–0:21.6: *Эффекты голоса → Мегафон / Радио*.
   - VO_03_03 и VO_07_01: **без** эффекта.
   - VO_05_03: дубликат клипа VO_05_02 (Ctrl+C / Ctrl+V), громкость −20 дБ.
   - VO_07_02: эффект *Приглушённый / Под водой (Muffled)* на минимальной силе (имитация стекла).
6. Финальные удары 1:19.0 / 1:19.8 / 1:20.6 — один и тот же файл трижды.
7. Нормализация: *Нормализовать громкость (Normalize loudness)* на голосах. Общий пик ниже 0 дБ.

**Проверка в наушниках и на динамике телефона.** На телефоне низы пропадают, поэтому удары и бас должны иметь и среднечастотную «атаку».
