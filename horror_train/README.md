# «НЕ ВЫХОДИТЕ ИЗ ПОЕЗДА» — производственный пакет

Вертикальный хоррор-ролик, 1:22, 9:16 / 1080 × 1920 / 30 fps, для TikTok, YouTube Shorts и Reels.

**Логлайн:** поезд № 317 встаёт в буране посреди степи. Проводник запрещает открывать двери, «даже если кто-то просит о помощи». Потом за дверью кто-то говорит детским голосом, и тот же голос, слово в слово, звучит из пустого конца коридора. Последнее объявление звучит голосом проводника, но не через громкоговоритель.

## Структура папок

```
horror_train/
├── 00_docs/              сценарий, промпты, озвучка, звук, монтажный план
├── 01_shotlist/          shotlist.csv (кадры), audio_cues.csv (звуковые метки)
├── 02_images/            сгенерированные кадры: S03B_v01.png, S02A_on_v02.png …
├── 03_video_clips/       анимированные кадры: S01A_v01.mp4 …
├── 04_audio/
│   ├── sfx/              настоящие звуки (имена из 04_sfx_prompts.md)
│   ├── voice/            записи голосов: VO_05_02_take2.wav …
│   ├── music/            дрон
│   └── temp/             ГОТОВО: temp_mix.mp3 (черновой микс по таймкодам) + placeholders/ (заготовки)
├── 05_subtitles/         ГОТОВО: subtitles_ru.srt
├── 06_overlays/          ГОТОВО: титры PNG, силуэт, CCTV-оверлеи, VHS-шум
├── 07_animatic/          ГОТОВО: animatic.mp4 — раскадровка во времени со звуком
├── 08_capcut_project/    проект CapCut
├── 09_export/            финальные MP4
└── tools/                скрипты
```

**Имена файлов:** `<ID кадра>_<вариант>_v<номер>.<расш>`, например `S06A_flash_v03.png`. Скрипт проверки находит кадр по префиксу ID.

## Что уже сделано скриптами

- **Титры** (`06_overlays/title_*.png`): 1080 × 1920, прозрачные, моноширинный шрифт с аналоговым RGB-расхождением, уже стоят в нужном месте кадра.
- **CCTV-оверлеи** (`cctv_03B.mp4`, `cctv_07.mp4`): тикающие часы камеры и мигающий REC. Накладывать в режиме **«Экран»**. Часы в финале доходят ровно до 03:41:00 — в момент обрыва записи.
- **VHS-шум** (`vhs_noise.mp4`): бесшовная петля 6 сек.
- **Силуэт** (`overlay_silhouette.png`): для спрятанной детали на 0:05.5.
- **Черновой звук** (`04_audio/temp/temp_mix.mp3`): ветер с автоматизацией, стук колёс с торможением, реле, помехи, удары, дуга, бас — синтезированы по `audio_cues.csv`. Это разметка: показывает, где и насколько громко должен звучать каждый звук. Заготовки по отдельности лежат в `placeholders/`. Финальные звуки лучше сгенерировать по промптам.
- **Аниматик** (`07_animatic/animatic.mp4`): весь ролик во времени — ID кадра, описание, титры, субтитры, звуковые метки и вспышки. Его можно сразу посмотреть и проверить ритм, а потом использовать как подложку в CapCut.

Пересобрать (после изменения таблиц):

```bash
pip install numpy pillow          # + ffmpeg в PATH
python3 tools/build_assets.py     # всё; или: titles cctv noise audio animatic
python3 tools/check_project.py    # проверка таблиц и список недостающих кадров
```

`temp_mix.wav` не хранится в git (16 МБ): он появляется после `build_assets.py audio`. В CapCut можно брать `temp_mix.mp3`.

## Порядок работы

1. Посмотри `07_animatic/animatic.mp4` в наушниках. Если ритм не устраивает, правь `shotlist.csv` / `audio_cues.csv` / SRT и пересобирай.
2. Сгенерируй картинки по `02_visual_prompts.md`. Начни с **S02A_on** и **S03B**: это эталон вагона. Остальные кадры интерьера генерируй со ссылкой на них (`--cref` / image reference / редактирование).
3. Анимируй 4 кадра I2V (S01A, S01B, S04B, S05A).
4. Запиши или сгенерируй голоса по `03_voiceover.md` и звуки по `04_sfx_prompts.md`.
5. `python3 tools/check_project.py` — все кадры на месте?
6. Монтаж по `05_capcut_edit_plan.md`.
7. Чек-лист ниже → публикация.

## Чек-лист перед публикацией

**Изображение**
- [ ] 1080 × 1920, 30 fps, 1:15–1:30, финал — жёсткий срез, без логотипа CapCut (удалить финальную заставку)
- [ ] Существо ни разу не видно целиком: только силуэт, без лица, голова за рамкой
- [ ] Аварийная лампа — единственное тёплое пятно, всё остальное сине-серое
- [ ] Нет случайного текста, логотипов, вотермарков генераторов на кадрах (особенно на табличках в вагоне)
- [ ] Вагон узнаваемо один и тот же во всех кадрах интерьера
- [ ] Все 8 спрятанных деталей на месте (таблица в `01_script.md`), силуэт на 0:05.5 едва различим, но различим на паузе
- [ ] Титры и субтитры не перекрыты интерфейсом TikTok: нижние 20 % и правые 15 % кадра свободны от важного

**Звук**
- [ ] Хук-титр читается в первые 2 сек и без звука
- [ ] Три окна тишины на месте: 0:12.6, 0:59.2, 1:16
- [ ] Второе «Я замёрз» — копия первого, а не новый дубль
- [ ] Последняя фраза проводника (0:21.8) и финальное объявление (1:05.8) — без помех динамика
- [ ] Черновой `temp_mix` выключен на таймлайне
- [ ] Ничего не клиппует; проверено в наушниках и на динамике телефона
- [ ] Права на все звуки: сгенерированы или CC0, авторы CC-BY указаны в описании

**Публикация**
- [ ] Обложка: кадр S06A_flash (силуэт вдали) + текст «НЕ ОТКРЫВАЙТЕ ДВЕРЬ»
- [ ] Подпись без спойлера, вопрос к зрителю. Например: *«Поезд № 317, 14 января 1999. Запись с камеры вагона 7. Вы бы открыли?»*
