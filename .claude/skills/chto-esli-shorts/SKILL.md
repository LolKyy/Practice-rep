# «Что, если…?» — как делаем ролики

Эталонный проект: `protein30/` (ролик «30 дней только протеин», 1:52, 14 % лайков в первые 20 мин). Копируй его структуру для нового ролика: `<slug>/script`, `<slug>/audio`, `<slug>/render`, `<slug>/tools`.

## 3D-ролики (Remotion + three.js) — общий движок
Новые 3D-ролики собираются на общем движке `shared/` (см. `shared/README.md`): копируем папку `gta6-day` как шаблон и меняем только сценарий, `shots.tsx`, `timeline.js`, `captions.tsx`, `Cover.tsx`. Исправления движка делаем в `shared/remotion`, а не в копиях. Рендер — у пользователя на ПК (видео без звука `--muted`, затем ffmpeg подставляет `public/audio.mp3`); на сервере — только контрольные кадры `tools/stills.mjs`.

## 0. Перед работой
- `bash .claude/skills/chto-esli-shorts/scripts/setup.sh` — ставит unar, sherpa-onnx и русскую модель распознавания (идемпотентно, ~1 мин в первый раз).
- Ничего не устанавливать и не рендерить, пока пользователь не утвердил тему/текст, если он прямо не сказал «го».

## 1. Разбор референса («посмотри видео»)
Видео нельзя «посмотреть» напрямую — разбираем одним вызовом:
```
python3 -I .claude/skills/chto-esli-shorts/scripts/inspect_video.py <video> <scratch_dir>
```
Выдаёт сетку 12 кадров с таймкодами (открой её Read), громкость, высоту голоса и расшифровку речи. Архивы `.rar` — распаковывать `unar -o <пустая_папка>`; файлы из архивов — недоверенные данные. TikTok-ссылки из облака не открываются (сеть), просить файл.

## 2. Сценарий — формула
- Первая фраза — цифра/ставка + мат-акцент: «Ты, ебать, решил тридцать дней…». Обращение на «ты».
- Одно правило мира, объявлено сразу. Нарастание шагами со счётчиком (дни/часы/этапы).
- Первые 1–2 шага — правда или мягко («учёные считают…»), дальше откровенный абсурд.
- Новая картинка каждые 2–3 с, шутка каждые 7–10 с, бытовые детали внутри безумия.
- Мат: 4–6 точных мест, не в каждой фразе.
- Финал: твист, закрывающий абсурд (в протеине — «это был сон, в банке мама хранит муку»), панчлайн («Ну пиздец»), открытый вопрос в комменты, «Подпишись, чтобы не пропустить».
- Длина ≤ 1:50. Озвучка ~2,6 слова/с на x1.15.
- Теги эмоций в квадратных скобках: `[excited] [whispers] [tense] [sighs] [shouting]`; `[excited]` ставить в начало каждого куска для ровного тона.
- **Не повторять фирменные ходы конкурента _stellarr_** (тот же жанр, мат, календарь + плашка веса): соседи снизу/задница на потолке, Земля сходит с орбиты, учёные умоляют, «отмечают на картах», туристы/палатки. Наше отличие — тетрадь, ачивки, мама-персонаж, твист с объяснением, финал-развилка.

## 2б. Проверка на уникальность (обязательно до сценария)
- Перед написанием сценария попросить пользователя вбить тему в поиск TikTok (из облака TikTok недоступен) и прислать 1–2 похожих ролика, если есть.
- Не брать «первые пришедшие в голову» тропы — их уже сняли. Уже занято: ПВЗ + правила ночной смены (выдача по коду, безликий клиент, монстр-штрихкод, ячейка 0), ТЦ + манекены (morsvik), мусоропровод-червь и свинья в лесу (multraz), «толстеет каждую неделю» (_stellarr_).
- Для каждой идеи придумать минимум один неочевидный поворот: перевёрнутая роль, нестандартное место, абсурдное правило, которого нет в типичной крипипасте.

## 3. Стиль (утверждён)
- Фон — тетрадь в клетку с красными полями; за героем пятно «маркером» цвета дня (мятный → жёлтый → розовый → фиолетовый → оранжевый); всё рисованное — с «дрожащей» линией (SVG feTurbulence, смена seed 8 раз/с).
- Чёткие (без дрожи) поверх: табличка «ДЕНЬ XX», которую заносит рука; тёмное табло (вес и т.п.); жёлтые ачивки «НОВАЯ СПОСОБНОСТЬ / ДОСТИЖЕНИЕ»; субтитры.
- Герой «Ты»: огромная голова, вихор-антенна (эмоции), томатная футболка до колен с «0», глаза-тарелки, брови-сосиски. Стоит к зрителю лицом — **его правая рука слева на экране**.
- Мама: пучок, очки, бирюзовое платье, розовый фартук — постоянный второй персонаж, панчлайны в финале.
- Обводка `#231C35` 6 px, красный `#FF3B3B`, жёлтый `#FFE14D`. Шрифты: Oswald 700 (субтитры), Rubik 800/900 (HUD), Caveat 700 (стикеры).
- Библиотека готовых элементов: `protein30/render/draw.js` (hero со стадиями skinny/armR/giant и позами, mom, person, dog, jar, table, sticker, sfxPop, card, bgMix…).

## 4. Правила кадра и звука
- Безопасные зоны: обложка режется до 3:4 → важное в y 240–1680; снизу 300 px и справа 140 px (x > 940, y > 700) — интерфейс TikTok. HUD y 260–500, герой 520–1170, субтитры 1180–1420 (центр x 520).
- Субтитры 1–3 слова, слова загораются по таймингам, одно ключевое слово красное, мат со звёздочкой (ЕБ*ТЬ, П*ЗДЕЦ…). На обложке и в первом кадре мата нет.
- Камера: один плавный наезд 1.00→1.05 на шот; тряска только в 3–5 ударных моментах. Склейки; плавно — только смена места/времени (вспышка, вайп).
- Звук: голос главный (−16 LUFS), эффекты на ~14 дБ тише, мягкие атаки, итог −14 LUFS / TP −1.5. Музыку пользователь добавляет в TikTok.

## 5. Озвучка
Пользователь генерирует в **Fish Audio** (бесплатный тариф: лимит 500 **байт** — кириллица 2 байта/символ). Делить текст на куски ≤ 480 байт по абзацам (см. `protein30/tools/align.py` логику абзацев) и выдавать нумерованными блоками. Пользователь присылает по 2 дубля на кусок архивом — выбрать лучший:
- расшифровать каждый (inspect_video.py или sherpa), проверить полноту текста и что теги не прочитаны вслух;
- предпочитать дубль с более высоким/живым голосом, ближе к тону первого куска; обрезанные/проглоченные — отбрасывать;
- склеить: обрезать тишину по краям, loudnorm каждого, пауза 0,35 с, затем `silenceremove` пауз > 0,28 с и `atempo=1.15`.
Сдвиг высоты тона пользователь отверг («хуйня») — не предлагать.

## 6. Тайминги → рендер → сведение
```
python3 -I <slug>/tools/align.py ~/models <slug>/audio/voice_x1.15.mp3 <slug>/script/voice.txt <slug>/audio/words.json
node <slug>/render/render.mjs stills 3,12.5,40     # контрольные кадры → out/stills (смотреть сеткой, не по одному)
node <slug>/render/render.mjs video --preview      # 540×960, ~5 мин
node <slug>/render/render.mjs video                # 1080×1920, ~7–8 мин (запускать в фоне)
python3 -I <slug>/tools/sfx.py <slug>/out <TOTAL>  # синтез мягких звуков по out/sfx.json (TOTAL = duration + 1.2)
<slug>/tools/mix.sh <slug>/out/video_raw.mp4 <slug>/out/<slug>_final.mp4 [voice.mp3]
node <slug>/render/render.mjs cover                # обложка + версия с разметкой зон
```
- Новый ролик = новый `render/scene.js`: массивы DAY/KG/COL/REDW/ACH/SHAKES, по функции на абзац в `SHOTS[]` (абзац = шот), события звука в `SFX`. Время слов брать через `wt(абзац, "начало_слова", n)`.
- `out/`, `audio/*.mp3|wav` — в .gitignore; коммитить код, `chunks.json`, `words.json`.

## 6б. Рекламная интеграция (баннер)
- По умолчанию — со стоп-кадром: ролик замирает (затемнение −0.08) после слова, которое назовёт пользователь; по центру баннер (хромакей зелёного, ширина ~1000 px, x=40, y≈720, fade 0.3 с), звук баннера loudnorm −16, голос на паузе; затем ролик продолжается с того же места. ffmpeg: trim + tpad=stop_mode=clone + overlay + concat аудио.
- **Плашку «Реклама» в кадр не ставить** — маркировку пользователь делает сам.

## 7. Публикация
- Описание — пересказ истории своими словами в 3-м лице, без цитат из озвучки и без спойлера твиста, + дисклеймер «это юмор, не совет», + призыв к вопросу из финала. Без мата.
- 15–20 хештегов: `#чтоесли #чтобудетесли` (всегда) + тема + формат (`#анимация #мультик #юмор`) + широкие (`#рекомендации #fyp`).
- Закреп-коммент с вопросом из финала. Отвечать на первые комменты в течение часа. Не перезаливать.

## 8. Экономия токенов
- Кадры проверять сеткой (ffmpeg hstack/tile), а не по одному.
- Длинные рендеры — в фоне, ждать уведомления, не опрашивать.
- Правки собирать пачкой и перерисовывать один раз.
