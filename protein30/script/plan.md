# План производства — «30 дней только протеин»

Всё делается в облаке без видеокарты: Remotion (React) + SVG/Canvas. Рендер 1:30 — ориентир 7–10 мин.

## Шаги
1. **Лист героя (на утверждение).** Claude рисует «Ты» и Палыча в SVG: 9 эмоций героя, 3 позы Палыча, руку с карточкой, плашки статов. Рендер 3–4 стоп-кадров → ты смотришь и правишь. Ничего дальше без «ок».
2. **Озвучка.** ElevenLabs, модель Eleven v3, голос George: stability 0.50, similarity 0.75, speed 1.00. Текст — `voice.txt`, по абзацу = шот. Запрос через `/with-timestamps` → аудио + тайминги каждого символа.
   - Если API недоступен из облака: генеришь в браузере сам и кидаешь mp3, а тайминги снимаем через whisper.cpp (или forced alignment ElevenLabs).
3. **Тайминги.** Скрипт превращает таймстемпы в слова → субтитры по 1–3 слова, красное слово из раскадровки, начала/концы шотов.
4. **Анимация в Remotion.** Шоты из `storyboard.md` как компоненты; фоны-лучи, карточка дня, статы, звукоподражания, вставки-улики. Камера: один наезд на шот, ⚡-моменты отдельно.
5. **Превью.** Стоп-кадры каждого шота (PNG) + черновой рендер в 540×960 → правки.
6. **Звук.**
   - Музыка: лёгкий игривый трек (Pixabay Music — проверить, что разрешено в соцсетях; для коммерции — Epidemic/Artlist).
   - SFX: Freesound (фильтр CC0) / Kenney Audio. У каждого звука fade-in 10–30 мс, без резких атак.
   - Голос 0 дБ, эффекты на −12…−15 дБ ниже голоса, музыка −20…−24 дБ с приглушением под голосом.
   - Итог: ffmpeg `loudnorm=I=-14:TP=-1.5:LRA=11`.
7. **Финальный рендер** 1080×1920, 30 fps, H.264, + обложка PNG 1080×1920 с проверкой обрезки 3:4.
8. **Коммит** в эту папку (без тяжёлых mp4/wav, если не попросишь).
